# QuickNotes App

QuickNotes is a simple browser-based note-taking application built with HTML, CSS and JavaScript. It allows users to create notes, organise them by category, search through existing notes, delete notes and keep their notes saved in the browser using localStorage.

## Features

- Add notes with Personal, Work or Study categories
- Validate note input
- Limit notes to 200 characters
- Display note creation date and time
- Delete individual notes
- Search notes in real time
- Case-insensitive searching
- Display the total number of notes
- Persist notes using localStorage
- Responsive layout for smaller screens

## How to Run Locally

1. Clone the repository:

   git clone https://github.com/Mason-hun/quicknotes-app.git

2. Open the project folder.

3. Open index.html in a web browser.

   Alternatively, use the Live Server extension in VS Code for a better development experience.
